Kindle · Keeping Books Safe
Teaching AI to Write Secret Codes

Kindle locks every e-book with secret codes so it can't be stolen. I built an AI that invents and tests those codes on its own.

Turn the page →
The problem

Codes used to be hand-written

Someone had to write each secret code by hand. Slow, and if a hacker cracks one, lots of books are exposed at once.

By handthe old, slow way
The idea

Let AI invent the codes

AI writes a new secret code, then checks its own work to make sure it actually keeps things locked. If it's wrong, it fixes itself and tries again.

70K+codes created so far
The trick

Speaks two languages

Different Kindles run different programming languages (C++ and Java). The AI writes the code once, translates it, and double-checks the translation still works.

2languages, auto-translated
The reach

It's on real devices

These AI-made codes didn't just sit in a lab, they shipped out and run on real Kindles in people's hands around the world.

500K+devices running it
Why it's safer

More codes = harder to crack

Because the AI can make tons of different codes, every book can get its own. A hacker who cracks one learns almost nothing about the rest.

Eachbook gets its own lock
The payoff

Months of work → weeks

What used to take about two months of hand-writing and testing now takes under a month, because the AI does the heavy lifting and checks itself.

2mo→<30dfaster to ship
In one line

The whole thing

An AI that invents, tests, and translates the secret codes that keep Kindle books from being stolen, faster and safer than doing it by hand.
